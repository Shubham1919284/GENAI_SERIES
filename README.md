## Repository layout

- `apps/` — Example scripts and small applications (Q&A bots, SQL agent examples, HTML demos).
- `env/` — A local Python virtual environment (optional; may already exist).
- `GenAI_Sheriyans/` — Project subfolder with additional examples and requirements.
- `notebooks/` — Jupyter notebooks used for demos and interactive exploration.

## Quick start

Prerequisites: Python 3.10+ (this workspace includes a `env/` created with Python 3.12).

1. (Optional) Create a fresh virtual environment and activate it:

```powershell
python -m venv env
env\Scripts\Activate.ps1   # PowerShell
```

2. Install dependencies. There are multiple `requirements.txt` files in subfolders — install the ones you need. Example (from project root):

```powershell
pip install -r GenAI_Sheriyans\requirements.txt
pip install -r notebooks\requirements.txt
```

3. Run an example script (from project root):

```powershell
python apps\1_qna_bot.py
python apps\4_sql_agent.py
```

4. Open and run notebooks with Jupyter:

```powershell
jupyter notebook
# then open files under the notebooks/ folder in your browser
```
